# Security Policy

## Supported versions

This repository is primarily an educational reference. Security fixes and documentation corrections are accepted for the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed credential.

Report it privately to the repository owner with:

- a clear description of the issue;
- the affected file, component, or URL;
- steps to reproduce it safely; and
- recommended remediation, if known.

Secrets such as passwords, API keys, OAuth client secrets, and connection strings must be supplied through environment variables or a managed secret store—never committed to the repository.
